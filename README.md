# szilassi

Finding an all-face-touching polyhedron on 12-faces.

## Instructions

Create duals of triangulations of the orientable surfaces of genus 6 with 12 vertices.

```console
./dual.py < data/manifolds_lex_d2_n12_o1_g6.txt > data/manifolds_lex_d2_n12_o1_g6_duals.txt
```
